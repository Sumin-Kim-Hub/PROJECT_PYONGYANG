## 1. 한 문장 목표

**"폰 하나로 명령하고, 결과를 보고받고, 중요한 일은 내가 승인하는 개인 AI 자동화 시스템"**을 AI Pickle 같은 유료 서비스 없이, 검증된 무료 오픈소스를 조합해서 만든다.

### 3-2. 게임 프로젝트와 분리하는 방법 (추천)

| 방법 | 장점 | 단점 | 추천 |
|---|---|---|---|
| **A. 새 비공개 저장소 `ai-command-center`** | 완전 분리, 비공개, 권한·자동화 독립 | 저장소를 새로 만들어야 함 | ⭐ **추천** |
| B. 게임 저장소 안 하위 폴더 | 당장 편함 | 공개 저장소라 설계·로그가 노출, 자동화 섞임 | ❌ |
| C. 게임 저장소의 별도 브랜치 | 파일은 분리됨 | 이력이 섞이고 헷갈림 | ❌ |

**진행 방법**
1. (사용자) GitHub 앱/웹에서 새 저장소 생성: 이름 `ai-command-center`, **Private**, README 체크.
   - 이 세션은 권한상 새 저장소를 직접 만들 수 없습니다 (현재 저장소로만 범위가 제한됨).
2. (Claude) 다음 세션에서 그 저장소를 연결 → 이 폴더의 문서를 옮김.
3. (Claude) 게임 저장소의 작업 브랜치에서 `ai-command-center/` 폴더 제거. `main`은 처음부터 건드리지 않음.

> 지금 이 문서들이 게임 저장소의 **작업 브랜치**에 잠시 들어가 있는 이유: 폰에서 바로 확인할 수 있게 하기 위함입니다. 문서에는 비밀번호·개인정보가 없습니다. 그래도 저장소가 공개라면 브랜치 내용도 공개라는 점은 알고 계셔야 합니다.

### 3-3. 지금 Claude Code(안드로이드 + 클라우드)에서 가능한 것 / 불가능한 것

| 구분 | 가능 ✅ | 불가능 ❌ / 제한 ⚠️ |
|---|---|---|
| 코드·문서 | 작성, 수정, 테스트 실행 (Python/Node) | — |
| GitHub | 연결된 저장소 읽기/쓰기, 브랜치 푸시, PR 작성 | ⚠️ 허락된 저장소만. 새 저장소 생성은 직접 해야 함 |
| 웹 조사 | 웹 검색, 문서 읽기 | ❌ 로그인이 필요한 사이트(네이버, 카드사 등) |
| 프로그램 실행 | 작업하는 동안 컨테이너에서 실행·테스트 | ❌ **24시간 상시 실행 불가** (세션 끝나면 컨테이너 회수) |
| 비밀 정보 | — | ❌ 채팅에 API 키 붙여넣기 금지. GitHub Secrets에 직접 입력해야 함 |
| 외부 계정 | — | ❌ Telegram 봇 생성(BotFather), Google·Meta 가입은 사용자가 직접 |
| 내 폰·노트북 데이터 | — | ❌ 접근 불가 (사진, 문자, 앱 데이터 등) |
| 결과 확인 | GitHub 앱/웹에서 문서·로그 보기 | ⚠️ 폰에서 웹 대시보드 띄우기는 노트북 이후 |

**결론**: Claude Code는 **"만드는 도구(공장)"**이고, 실제로 매일 돌아가는 시스템은 **GitHub Actions(지금)** + **노트북(나중)**에서 돌아가야 합니다.

## 4. 기능별 "어떻게 현실적으로 만들 것인가"

조사 중 중요한 사실을 확인했습니다: **네이버 블로그 글쓰기 API는 2020년 5월에 종료**되었습니다 ([뉴스핌 2020-04-13](https://newspim.com/news/view/20200413000737)). 그래서 네이버 자동 게시는 공식적으로 불가능하고, 브라우저 자동 조작으로 하면 계정 정지 위험이 큽니다.

| 기능 | 실현 방법 | 자동화 수준 | 단계 |
|---|---|---|---|
| 뉴스(국내/글로벌/할리우드) | RSS 수집 → AI 요약 → Telegram | 완전 자동 | 6 |
| 최신 트렌드 | 네이버 데이터랩 API(무료, 앱 등록 필요) + 뉴스 키워드 분석 | 완전 자동 | 6 |
| OTT 추천 | TMDB API(무료, 비상업·출처 표기) 의 한국 서비스 정보 | 완전 자동 | 6 |
| 네이버 블로그 글 | AI 초안 작성 → 승인 → **사용자가 복사·붙여넣기로 게시** | 반자동 | 6 |
| Instagram 카드뉴스 | 카드 이미지 자동 생성(PNG) → 승인 → 사용자 업로드 (나중에 Meta 공식 API 검토) | 반자동 | 6 |
| 콘텐츠 예약·기록 | 예약 목록 + 게시 기록을 데이터베이스/마크다운으로 관리 | 자동 | 6 |
| 네이버 리뷰 | 사용자의 **실제 경험 메모** → 문장 다듬기만. 경험 없는 리뷰 작성 거부 | 보조 | 7 |
| 출석체크·리워드 | 자동 클릭 ❌ → 매일 알림 + 체크리스트 버튼 + 적립 현황 기록 | 알림·기록 | 7 |
| 설문조사 적립금 | 사이트 목록·적립금 수동 기록, 마감 알림. 대리 응답 ❌ | 알림·기록 | 7 |
| 카드 소비·포인트 | 카드사 앱에서 **내가 내려받은 엑셀/CSV**를 노트북에서 분석 | 반자동 | 8 |
| 휴대폰 요금·사용량 | 공개 API 없음 → 월 1회 수동 입력/스크린샷 기록 + 요금제 비교 | 반자동 | 7 |
| 공공지원금·혜택 | 공공데이터포털의 공공서비스(혜택) 정보 API (존재 여부·조건 **확인 필요**) | 자동 | 8 |
| 일정·이메일 | Google Calendar / Gmail 공식 API (무료, OAuth) | 자동 + 승인 | 9 |
| 금융 알림 | 분석 결과 요약 알림 (상세 금액은 대시보드에서만) | 자동 | 8 |
| 결제·이체 | **자동화하지 않음.** 할 일 알림까지만 | 없음 | — |
| 기분·수면·감정 기록 | Telegram 버튼으로 하루 1분 기록 → 로컬 저장 → 주간 패턴 | 자동 | 10 |
| 진료 준비 | 기록 요약 → 진료 전 질문 목록 작성 (의학적 판단 아님) | 보조 | 10 |
