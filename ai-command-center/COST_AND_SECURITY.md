### 1-2. 개발 단계 절약 (Claude Code 사용량)

1. **RESUME.md 방식**: 매 세션 시작 시 짧은 요약 파일 하나만 읽고 시작 → 큰 파일 반복 읽기 방지
2. **한 세션 = 한 단계 일부**: 작은 단위로 끝내고 커밋 → 긴 대화로 인한 토큰 낭비 방지
3. **요청 방법 예시**: "ROADMAP 3단계 진행해줘" 처럼 문서 번호로 지시 → 설명 반복 불필요
4. 반복·단순 작업(파일 이름 정리 등)은 짧게 요청, 설계 재논의 최소화
5. Claude Code는 **만드는 데만** 사용. 매일 실행되는 작업에 Claude Code 예약 기능 사용 안 함

### 1-3. 운영 단계 절약 (AI API)

1. **AI 없이 되는 건 AI 안 씀**: RSS 수집, 정렬, 금액 합계, 날짜 계산은 일반 코드로
2. **묶음 처리**: 뉴스 30건을 30번이 아니라 1번에 요약
3. **캐시**: 같은 기사·질문은 다시 호출하지 않음
4. **작은 모델 우선**: Flash/Haiku 기본, 품질 필요 시에만 상위 모델
5. **한도 장치**: 일/월 호출 수·예상 비용 상한 → 초과 시 자동 정지 + Telegram 알림
6. **결제 수단 미등록 상태 유지**(Gemini): 실수로 과금될 일 자체를 없앰

## Part 2. 보안

### 2-1. 비밀 정보 관리 규칙

| 규칙 | 방법 |
|---|---|
| API 키·토큰을 코드·문서·채팅에 쓰지 않음 | GitHub Secrets / 노트북 `.env` |
| `.env`, `*.db`, `data/private/` 는 GitHub 제외 | `.gitignore` + CI의 gitleaks 검사 |
| 로그에 비밀 출력 금지 | 로그 출력 시 자동 가림 처리 + 테스트 |
| 키 유출 의심 시 | 즉시 재발급(BotFather `/revoke`, AI Studio 키 삭제) → 절차를 `docs/INCIDENT.md`에 기록 |
| GitHub 계정 | 2단계 인증(2FA) 켜기 권장 |

### 2-2. 접근 통제

- Telegram: `ALLOWED_CHAT_IDS` 외 모든 메시지 무시·기록
- 대시보드: Tailscale 비공개망 + 비밀번호. 인터넷 포트 개방 금지
- 노트북: BitLocker, Windows 로그인 비밀번호
- 외부 플러그인·스킬 자동 설치 금지 (OpenClaw ClawHub 악성 스킬 341개 사례)
- 사용하는 오픈소스는 버전 고정, 정기 업데이트(보안 패치)

### 2-3. "밖으로 나가는 행동"은 전부 승인제

| 행동 | 승인 |
|---|---|
| Telegram으로 나에게 보고 | 불필요 |
| 블로그·SNS 게시 | 필수 (현재는 사용자가 직접 게시) |
| 이메일 발송, 일정 수정 | 필수 |
| 결제·이체·금융거래 | **자동화하지 않음** (알림만) |
| 새 외부 서비스 연결 | 필수 |

모든 승인·거절·실행은 **감사 로그**(시간, 내용, 결과)에 남깁니다.

### 2-4. 금융 데이터 원칙

1. **읽기 전용**: 시스템이 돈을 움직이는 기능은 만들지 않음
2. **파일 가져오기 방식**: 사용자가 직접 내려받은 내역 파일만 분석. 은행·카드사 아이디/비밀번호 저장 금지, 스크래핑 금지
3. **로컬 처리**: 노트북 밖으로 원본 금액·가맹점 정보 전송 금지 (AI는 로컬 모델 또는 사용 안 함)
4. **마스킹**: 카드번호·계좌번호는 끝 4자리만 저장
5. **최소 보관**: 원본 파일은 분석 후 삭제 옵션 제공
6. Telegram 보고는 요약 수준만 ("식비 지난달 대비 +12%")

### 2-5. 건강·심리 데이터 원칙

- 별도 암호화 DB, 로컬 모델만, 외부 전송 0
- 진단·처방성 문구 금지 — 기록·정리·진료 준비 보조까지만
- 위기 신호 문구 감지 시 전문 상담 안내 (자살예방상담전화 109, 정신건강위기상담 1577-0199)

### 2-6. 하지 않는 것 (명시)

- CAPTCHA 우회, 봇 탐지 회피, 자동 로그인·자동 클릭으로 출석·설문 수행
- 경험하지 않은 리뷰 작성, 설문 대리 응답
- 사용자 승인 없는 게시·발송·결제
- 서비스 약관이 금지하는 자동 수집
