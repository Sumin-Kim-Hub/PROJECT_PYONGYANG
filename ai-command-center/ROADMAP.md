# ROADMAP — 12단계 개발 계획

**표기**: 👤 = 사용자가 직접 할 일 · 🤖 = Claude가 할 일 · ✔️ = 완료 기준(증거)

**규칙**
- 각 단계는 ✔️ 완료 기준을 **증거(스크린샷·로그·테스트 결과)** 로 확인해야 끝난 것으로 봅니다.
- 비용 발생·외부 가입·개인정보 접근·기존 파일 변경이 있는 단계는 시작 전에 사용자 확인을 받습니다 (⚠️ 표시).
- 단계 A(1~6)는 폰만으로 진행 가능, 단계 B(7~12)는 노트북 필요(일부 예외).

---

## 0단계 — 준비 (사용자 5~10분) ⚠️ 외부 가입·저장소 생성

| 할 일 | 방법 |
|---|---|
| 👤 비공개 저장소 생성 | GitHub 앱/웹 → New repository → `ai-command-center`, **Private**, Add README |
| 👤 Telegram 봇 생성 | Telegram에서 `@BotFather` → `/newbot` → 토큰 받기 (**채팅창에 붙여넣지 말 것**) |
| 👤 토큰 저장 | 새 저장소 → Settings → Secrets and variables → Actions → `TELEGRAM_BOT_TOKEN` 등록 |
| 🤖 다음 세션 시작 시 새 저장소 연결 | — |

---

## 1단계 — 프로젝트 기반 구축 (폰 가능)

- **작업**: 🤖 설계 문서 이전, 폴더 구조, `.gitignore`(.env·DB 제외), `.env.example`, `docs/STATUS.md`, `docs/RESUME.md`(다음 세션 시작용 요약 — 토큰 절약), CI(테스트 + gitleaks 비밀 검사)
- **프로그램**: GitHub, GitHub Actions, Python 3.12+, pytest, gitleaks
- **✔️ 검증**: CI 초록불 / 일부러 가짜 키를 넣은 테스트 브랜치에서 gitleaks가 실패하는지 확인 후 삭제
- **위험**: 게임 저장소 쪽 임시 폴더 정리 누락 → 체크리스트로 관리

## 2단계 — 핵심 시스템 설계·뼈대 (폰 가능)

- **작업**: 🤖 `core/` 작성 — 설정 로더, 로그, 저장소(SQLite), 승인 대기열 모델, 작업 실행기, `llm.py` 라우터(가짜 모델로 테스트)
- **프로그램**: Python, SQLite, pytest
- **✔️ 검증**: 단위 테스트 — 승인 안 된 작업은 실행되지 않음 / 민감도 `secret` 은 외부 모델로 절대 안 감 / 비용 한도 초과 시 중단
- **위험**: 과설계 → 지금 필요한 것만 만들고 나머지는 빈칸으로 둠

## 3단계 — Telegram 연결 (폰 가능) ⚠️ 0단계 토큰 필요

- **작업**: 🤖 메시지 보내기 모듈 + GitHub Actions 수동 실행 워크플로 "핑 테스트"
- 👤 봇에게 `/start` 보내기 (chat_id 확인용, Claude가 방법 안내)
- **프로그램**: Telegram Bot API, GitHub Actions
- **✔️ 검증**: 👤 폰으로 "연결 성공" 메시지 수신 스크린샷 / 허용되지 않은 chat_id로 보내기 차단 테스트
- **위험**: 토큰 유출 → Secrets만 사용, 로그에 토큰 출력 금지 테스트

## 4단계 — 모바일 웹 대시보드

- **단계 A(폰)**: 🤖 `docs/STATUS.md` 자동 갱신 + Telegram `/상태` 형식 보고서
- **단계 B(노트북)**: 🤖 FastAPI 대시보드 (홈·작업·승인 대기) → 11단계 이후 실제 접속
- **프로그램**: FastAPI, Jinja2, Pico.css, Tailscale(노트북 이후)
- **✔️ 검증**: 컨테이너에서 Playwright로 폰 크기 화면 스크린샷 / 비밀번호 없이 접근 시 차단 테스트
- **위험**: 대시보드 외부 노출 → 기본값을 `localhost` + Tailscale 전용으로

## 5단계 — AI 모델 연결 ⚠️ Google 계정으로 Gemini 키 발급(무료)

- **작업**: 👤 Google AI Studio에서 API 키 발급 → Secrets 등록 / 🤖 `llm.py`에 Gemini 연결, 사용량 기록, 캐시
- (선택) ⚠️ Claude API: 결제 수단 등록 + 월 상한 설정 필요 → 별도 승인 후
- **✔️ 검증**: 실제 요약 1건 성공 로그 / 무료 한도 초과(429) 시 재시도·포기 동작 테스트 / 월 사용량 보고
- **위험**: 무료 한도 변경 → 하루 1회 묶음 처리로 호출 수 최소화. 무료 등급 데이터 활용 정책 → 공개 정보만 보냄

## 6단계 — 콘텐츠 자동화 (폰 가능, 첫 실사용 기능)

| 순서 | 기능 | 확인 사항 |
|---|---|---|
| 6-1 | **아침 뉴스 브리핑**: 국내·글로벌·할리우드 RSS → 요약 → Telegram (매일 07:00 KST) | RSS 주소 실제 동작 |
| 6-2 | 트렌드 리포트: 네이버 데이터랩 API ⚠️ 네이버 개발자센터 앱 등록(무료) | 약관 확인 |
| 6-3 | OTT 추천: TMDB API ⚠️ 가입(무료) | 출처 표기 |
| 6-4 | 블로그 초안: 주제 → 초안 마크다운 → 승인 버튼 → `content-log/` 저장 → 👤 네이버에 붙여넣기 | 자동 게시 없음 |
| 6-5 | 카드뉴스: 템플릿 HTML → Playwright로 1080×1350 PNG → Telegram 전송 → 👤 업로드 | 폰트 라이선스 |
| 6-6 | 콘텐츠 예약표·게시 기록 | — |

- **✔️ 검증**: 3일 연속 아침 브리핑 도착 (Actions 실행 기록) / 카드뉴스 PNG 실물 확인 / 초안 승인→기록 흐름 테스트
- **위험**: Actions 예약 실행이 몇 분~수십 분 늦어질 수 있음 🔶 / 뉴스 저작권 → 요약 + 원문 링크만, 전문 복사 금지

## 7단계 — 생활 자동화 (일부 폰 가능)

- 출석체크·리워드: 사이트 목록 + 매일 알림 + `[완료]` 버튼 → 연속 기록·적립금 기록 (**자동 클릭·로그인 없음**)
- 설문 적립금: 사이트별 적립금 수동 기록, 출금 가능액 도달 알림 (대리 응답 없음)
- 네이버 리뷰: 👤 실제 방문 메모·사진 설명 입력 → 문장 다듬기. 경험 정보가 없으면 작성 거부
- 휴대폰 요금: 월 1회 사용량 입력 알림 → 요금제 적정성 비교
- **✔️ 검증**: 1주일 사용 후 체크리스트 기록 확인 / 리뷰 기능이 메모 없을 때 거부하는지 테스트
- **위험**: 약관 위반 → 자동 조작 기능 자체를 만들지 않음

## 8단계 — 금융 및 혜택 관리 (노트북 필요) ⚠️ 개인정보 접근

- 👤 카드사 앱/웹에서 이용내역 엑셀·CSV 내려받기 → 노트북 지정 폴더에 넣기
- 🤖 카드사별 파일 형식 변환기, 카드번호·가맹점 일부 마스킹, 분류(식비·교통 등), 월별 리포트
- 포인트·혜택: 카드 혜택 조건표(수동 입력) 대비 이번 달 실적 분석
- 공공지원금: 공공데이터포털 API (⚠️ 존재·활용 조건 먼저 확인) → 조건 맞는 혜택 알림
- AI 사용: `secret` 민감도 → **로컬 모델 또는 AI 없이 계산**
- **✔️ 검증**: 가짜(샘플) 내역 파일로 먼저 테스트 → 실제 파일은 사용자 확인 후 / GitHub·클라우드 전송 0건 확인(네트워크 로그)
- **위험**: 개인정보 유출 → 로컬 전용, Telegram에는 "이번 달 식비 지난달 대비 +12%" 수준만

## 9단계 — 개인 AI 비서 (노트북 필요)

- Telegram 대화형 명령 상시 응답 (노트북에서 폴링 봇 실행)
- Gmail·Google 캘린더 연동 ⚠️ Google OAuth 설정 (읽기 권한부터) — 직접 코딩 또는 n8n
- 개인 지식 저장·검색 (`/기록`, `/찾기`, SQLite FTS5)
- 반복 작업 등록 (`/매일 08:00 <작업>`)
- (평가) OpenClaw를 격리 환경에서 외부 스킬 없이 시험 → 도입 여부 판단 문서 작성
- (필요 시) LangGraph로 다단계 작업 + 승인 흐름
- **✔️ 검증**: 노트북 재부팅 후 자동 시작 / 메일 "보내기"는 반드시 승인 필요 테스트
- **위험**: 권한 과다 → Google 권한은 읽기부터, 쓰기는 별도 승인

## 10단계 — 심리 및 건강 기록 (후순위, 노트북 필요) ⚠️ 민감정보

- 매일 저녁 Telegram 버튼: 기분(1~5), 수면 시간, 한 줄 메모
- 주간 패턴 그래프(대시보드), 진료 전 요약·질문 목록 PDF
- 별도 암호화 DB, 로컬 모델만 사용, 의학적 판단·진단 문구 금지, 위기 상황 문구 감지 시 상담전화 안내(자살예방상담 109 등)
- **✔️ 검증**: 외부 전송 0건 / 내보내기 파일 사용자 확인
- **위험**: 민감정보 유출, 잘못된 조언 → 기록·정리만, 판단은 의료진

## 11단계 — Windows 노트북 이전 ⚠️ 프로그램 설치

1. 👤 Windows 업데이트, BitLocker(디스크 암호화) 켜기 확인
2. 👤 PowerShell에서 Claude가 준 설치 명령 실행: `winget install Git.Git Python.Python.3.12 Tailscale.Tailscale` (+ 필요 시 Docker Desktop, Ollama)
3. 👤 Claude Code 설치 → 저장소 복제
4. 🤖 `setup.ps1` 작성 → 👤 실행 → `selftest`
5. 👤 `.env` 직접 작성 (키 재입력)
6. 🤖 작업 스케줄러 등록 스크립트, 대시보드 Tailscale 접속 안내
- **✔️ 검증**: 폰(모바일 데이터, 와이파이 끈 상태)에서 Tailscale로 대시보드 접속 / 재부팅 후 봇 자동 응답
- **위험**: 노트북 사양 부족(로컬 모델) → 사양 확인 후 모델 크기 결정, 안 되면 `secret`은 AI 없이 처리

## 12단계 — 최종 테스트 및 패키징

- 전체 시나리오 테스트(아침~저녁 하루 흐름), 장애 시나리오(인터넷 끊김, 키 만료, 한도 초과)
- 백업·복원 연습 (새 폴더에 복원해서 동작 확인)
- 사용 설명서(비개발자용), 버전 태그 `v1.0`
- **✔️ 검증**: 체크리스트 전 항목 통과 증거, 보안 점검(비밀 스캔, 포트 스캔)
- **위험**: 문서와 실제 동작 불일치 → STATUS.md를 테스트 결과로 자동 생성
