# Android APK / iOS TestFlight 배포 가능성 검토 (V2.3)

> **이 문서의 모든 내용은 이 세션에서 직접 해 본 것이 아닙니다.** 이 환경에는 Godot, Android SDK, Xcode 가 없고 외부 다운로드도 막혀 있습니다. 아래는 일반적으로 알려진 절차와, 확인하지 못한 부분의 표시입니다. 실제 값(버전, 요금, 정책)은 해당 공식 문서에서 다시 확인하세요. APK 나 IPA 는 만들지 않았고, 만들어졌다고 말하지 않습니다.

## 1. Android APK
### 일반적으로 필요한 것 (Godot 4.x 기준, 미확인)
- **내보내기 템플릿**: 에디터 버전과 정확히 같은 버전(4.7.2)의 템플릿
- **JDK 17** 과 **Android SDK**(플랫폼 도구, 빌드 도구), 에디터 설정에 경로 지정
- **키스토어**: 디버그용은 에디터가 자동으로 쓰거나 만들 수 있음. 배포용은 직접 만든 키를 안전하게 보관해야 함(잃으면 업데이트 불가)
- 프로젝트 > 내보내기 > Android 프리셋: 패키지 이름(예: `com.example.pyongyang`), 아이콘, 최소 SDK, 권한. 이 게임은 오프라인이므로 인터넷 권한 불필요
- 결과: 디버그/릴리스 APK, 또는 스토어용 AAB

### 이 프로젝트에서 확인하지 못한 점
1. **폰에서 도는 Godot 에디터만으로 APK 를 내보낼 수 있는지** — 사용자는 폰에서 개발합니다. 안드로이드 에디터의 내보내기 지원 범위(템플릿 포함 여부, SDK 필요 여부)를 공식 문서로 확인하지 못했습니다. 이게 가능하면 제일 쉬운 길입니다.
2. 불가능하다면 PC(윈도/맥/리눅스) 또는 **GitHub Actions** 같은 CI 에서 내보내기. 이 저장소에 `.github/workflows/godot-check.yml` 템플릿을 넣었지만 **내보내기까지는 하지 않고 "오류 검사"만** 합니다. (내보내기 단계는 프리셋 파일 `export_presets.cfg` 가 필요하고 아직 없습니다.)
3. 프로젝트에 `export_presets.cfg` 가 없습니다. 에디터에서 한 번 프리셋을 만들어야 합니다.
4. 안드로이드 빌드에서 `res://assets/fonts/ui_ko.otf`, `res://assets/characters/` 가 없다는 점은 코드가 알아서 우회하지만(다른 글꼴/절차 모형 사용), 한글이 기본 글꼴에서 보이는지는 확인하지 못했습니다.

### 배포 경로 (일반 지식)
| 방법 | 필요한 것 | 비고 |
|---|---|---|
| APK 직접 설치(사이드로드) | APK 파일, 폰의 "출처를 알 수 없는 앱" 허용 | 가장 간단. 친구에게 파일로 전달 가능 |
| Google Play 내부 테스트 | 개발자 계정(1회 등록비), AAB, 앱 서명 설정 | 스토어 정책 검토 필요. 이 게임은 북한풍 가상 배경이라 **콘텐츠 정책/등급 설문을 꼼꼼히 확인**해야 함 |
| 기타 스토어/웹 | - | 이번 검토 범위 밖 |

## 2. iOS TestFlight
### 필요한 것 (일반 지식, 미확인)
- **Apple Developer Program 유료 가입**(연 단위 요금)
- **macOS + Xcode** : Godot 의 iOS 내보내기는 Xcode 프로젝트를 만들고, 서명·아카이브·App Store Connect 업로드는 Xcode 에서 함
- 서명 인증서, 프로비저닝 프로파일, 번들 ID, 앱 아이콘/실행 화면
- App Store Connect 에 앱 등록 후 빌드 업로드 → TestFlight 내부/외부 테스터 초대. 외부 테스터는 Apple 의 베타 심사가 필요
### 현실적인 판단
- **맥이 없으면 사실상 불가능**합니다. 대안은 클라우드 맥(CI 의 macOS 러너 등)이지만 서명 키를 CI 에 맡기는 설정이 필요하고, 이 프로젝트에서는 시도하지 않았습니다.
- 지금 단계(실행 0회, 폰에서 오류 수정 중)에서는 **iOS 는 권장하지 않음**. Android 에서 안정화된 뒤에 검토.
- 콘텐츠: 실제 국가·인물을 연상시키는 가상 설정이므로 심사에서 어떻게 판단될지 알 수 없습니다. 실존 인물 이름/모습은 이 프로젝트에 넣지 않았습니다(지도자도 등장하지 않음).

## 3. 권장 순서
1. 폰에서 V2.3 실행 → 오류 글씨 수집 → 수정 반복 (지금 가장 급함)
2. 오류 0개, `docs/V2.3_USER_TEST_GUIDE.md` 체크 통과 후 → 안드로이드 에디터 내보내기 가능 여부 확인(1순위) 또는 PC/CI 내보내기
3. 디버그 APK 를 친구 폰에서 실행해 보기(성능·터치·한글)
4. 그 다음에야 AAB/스토어/iOS 를 검토
