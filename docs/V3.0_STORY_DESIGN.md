# V3.0 스토리 설계 (가상 설정)

> 모든 인물·장소·사건은 이 게임을 위해 만든 **가상 설정**입니다. 실제 인물이나 실제 사건을 재현하지 않으며, 폭력·유혈 장면 없이 "선택과 대화"로만 진행됩니다. 코드는 쓰였지만 Godot 에서 실행한 적이 없습니다 (미검증).

## 큰 줄기: 4막 + 자유 플레이
| 막 | 이름 | 게임 안에서 일어나는 일 | 진행 판정 (코드) |
|---|---|---|---|
| ACT 1 | 평양 잠입 | 도시 탐험, 주민과 대화, 정보 수집, 통행증, 북부 검문소 | 임무 `q_v3_story` 시작 (자동) |
| ACT 2 | 도시의 비밀 | 통제구역, 중앙 청사·사저 잠입, 비공개 지출 장부 확보 | 북부 검문소 통과 / 특별 통행증 → 단계 1, `q_v23_leader` 가 2단계 이상 → 단계 2 |
| ACT 3 | 최고지도자 관저 | 장부를 들고 집무실로 들어가 지도자와 마주함 | 장부 `doc_v23_ledger` 소지 → 단계 3, 대면 장면을 본 뒤 → 단계 4 |
| ACT 4 | 권력 승계 | 선택에 따라 지도자가 됨 → 통치 모드 | 승계 선택 → 단계 5 (완료) |
| 이후 | 자유 플레이 | 캠페인 끝난 뒤에도 같은 게임에서 통치·건설·탐험 계속 | 지도자 모드는 저장됨 |

## ACT 3 대면 장면 (집무실)
1. 장부를 가진 채 집무실(실내 칸 13, 안쪽 큰 방)에 들어서면 0.5초마다 위치를 확인해 자동으로 시작됩니다. (V2.3 에서는 "지방 시찰 중"이던 지도자가 이때 나타납니다. 이전 설정과 모순되지 않도록, 장부 없이 들어가면 나타나지 않습니다.)
2. 화면이 어두워지고 → 책상 앞으로 이동 → 도입 카드(글 장면) 여러 장 → 밝아지며 지도자 대화 시작.
3. 대화 흐름: `시작 → 누구냐 / 왜 왔느냐 → 장부 이야기(지지 기반 표시) → 선택`.
4. 지지 기반 3가지 점수(0~100)가 계산되어 어떤 길이 열려 있는지 대사에 표시됩니다.

### 지지 기반 계산 (`v3_story.gd` `evaluate_support`)
| 지지 | 올리는 것 | 50 이상이면 열리는 길 |
|---|---|---|
| 주민 | 완료한 임무 수 ×5, 주민 신뢰 합계 ×3 (기본 20) | 공개 개혁 |
| 군부 | 특별 통행증, 기지 카드, 명단, 명령서, 지하 통로 지도, 북부 통과 (기본 10) | 군부 합의 |
| 측근 | 장부, 결재 문서철, 비서관 열쇠, 훈장, 선물·시계, 서재 단서 (기본 10) | 조용한 거래 |
| — | 항상 열림 | 유언 승계 |

→ 이전에 어떻게 플레이했는지(도움을 많이 줬는지, 어떤 물건을 모았는지)가 엔딩 선택 폭에 영향을 줍니다. "유언 승계"는 아무것도 못 모았어도 항상 선택 가능한 안전 장치입니다.

## ACT 4 승계: 4가지 길 (비폭력, 가상)
| 길 | 엔딩 이름 | 시작 지표 (예산/경제/만족/발전/자원/안정) | 충성도가 높은 인물 |
|---|---|---|---|
| 공개 개혁 | 엔딩 A — 광장의 낭독 | 1200 / 45 / 68 / 40 / 45 / 42 (만족도 높고 안정도 낮음) | 인민 대표 75, 군부 35 |
| 군부 합의 | 엔딩 B — 질서의 이름으로 | 1800 / 52 / 40 / 42 / 50 / 72 (안정도 높고 만족도 낮음) | 군부 대표 75, 인민 대표 35 |
| 조용한 거래 | 엔딩 C — 닫힌 문 뒤의 서명 | 3000 / 55 / 48 / 45 / 52 / 52 (예산 풍부) | 비서관 70, 경제 고문 65 |
| 유언 승계 | 엔딩 D — 마지막 부탁 | 1500 / 45 / 52 / 40 / 48 / 55 (균형) | 비서관 60, 경호대장 55 |

(수치 출처: `v3_data.gd` 의 `route_info()`.)

선택 순간: 대화 효과 `v3_succeed` → 대화 종료 대기 → 화면 어두워짐 → 지도자 NPC 제거 → 지도자 모드 켜기(옷, 경호, 수행원, 집무실·사저 권한, 통치 지표 초기화) → 집무실 책상 앞에 배치 → 승계 글 카드 + 엔딩 제목 카드 + 사용 방법 카드 3장 → 밝아짐 → 자동 저장.

## 지도자 모드에서 달라지는 것
- **복장:** 지도자 옷으로 교체 (`CharacterBuilder.player_override`).
- **출입:** 청사 정문 자동 통과, 집무실·사저·회의실 문 열림 (사저 열쇠 자동 지급).
- **경계:** 경비의 의심이 오르지 않음, 도시 경계 서서히 낮아짐.
- **수행:** 경호원 2명 + 수행 직원 1명이 따라다님 (멀어지면 가까이로 이동).
- **집무실 상호작용:** 창가(도시 조망), 책상(일정/연설), 회의 탁자(회의). 사저: 침대(아침까지 자기), 서재.
- **전용 차량:** 청사 앞 주차 자리에서 호출 → 기존 운전 시스템 그대로 사용, 내리기 가능.
- **특별 대화:** 비서관·경제 고문·군부 대표·인민 대표·경호대장·(사저의 전임 지도자) 와 모드 전용 대화.
- **도시 조망 카메라:** 청사 전경 / 도시 중심 / 개발 지구 3개 시점, 드래그로 회전, 가까이·멀리.

## 통치 시뮬레이션 요약
- 지표 6개: 예산, 경제, 만족도, 발전도, 식량·자원, 안정도 (예산 외에는 0~100).
- 현실 시간 약 60초(게임 시간 2시간)마다 한 번 계산. 수입 = 60 + 경제×1.2 + 발전도×0.6 + 건물 수입, 지출 = 70 + 유지비 + 배분 단계×20.
- 정책 15개(시행 즉시 효과 + 몇 번 동안 이어지는 효과 + 다시 쓰기까지 대기), 건물 12종(건설비·지표 효과·유지비·수입), 회의 카드 12장(선택에 따라 지표 변동), 국정 목표 12개(달성 시 예산 보상).
- 균형 장치: 70 넘으면 올리기 어려워짐, 식량 부족·빚·안정도 붕괴 때 불이익, 안정도 0.5 이하에 빠지면 비상 회복(예산 −500, 만족도 −10, 안정도 25로 복구).
- 파이썬으로 옮긴 모형에서 4가지 길 × 120 틱 모의 결과: 값 범위 유지, 무조작 방치는 천천히 나빠지고 적극 운영은 80~100 근처. **게임 안의 실제 값은 실행해 봐야 압니다.**

## 한계 (정직하게)
- 지도자와의 대면은 글 카드 + 대화 창 + 짧은 연출뿐이며, 움직이는 컷신·음성·표정 연기는 없습니다.
- 대면 장면 도중 플레이어가 대화 외 행동으로 장면을 피할 방법은 막아 두었지만(모드 3), 실제로 막히는지는 미검증입니다.
