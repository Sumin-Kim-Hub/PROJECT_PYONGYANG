# V3.0 직접 테스트 안내 (폰만으로)

> V3.0 는 한 번도 실행된 적이 없습니다. 아래는 **제가 못 한 테스트를 폰에서 하는 순서**입니다. 칸마다 `작동 / 안 됨 / 이상함` 만 적어 주셔도 충분하고, 빨간 오류 글씨는 그대로 복사해 주세요. (V2.3 안내 `docs/V2.3_USER_TEST_GUIDE.md` 의 기본 테스트가 먼저입니다.)

## 0. 준비
1. `PROJECT_PYONGYANG_V3.0.zip` 을 풀어 기존 폴더 위에 덮어쓰기. 보호 파일(world_builder, camera_rig, player, touch_controls, game_config)을 직접 손봤다면 그 파일 유지.
2. Godot 에디터에서 열고 **디버거 > 오류** 탭 확인. 빨간 글씨가 있으면 그것부터 보내 주세요.
3. 이전 저장 파일이 있으면 먼저 **이어하기**로 열어서 불러와지는지 보세요 (V3 호환 확인).

## 1. 자체 점검 (게임이 대신 확인, 약 10초)
- 새 게임 → 10초 대기 → 화면 위 검은 칸 `자체 점검 V3.0: 통과 N / 주의 N / 실패 N` 을 **스크린샷**.
- "V3" 가 들어간 줄(모듈, 데이터, 대화, 모의 통치, 건설 규칙)의 `실패`/`주의`가 중요합니다. 파일 `user://v22_selftest.txt` 에도 저장.

## 2. 가장 빠른 시험: 지름길 스위치 (`scripts/data/feature_flags.gd`)
| 스위치 | 효과 |
|---|---|
| `V3_TEST_LEDGER = true` | 시작 7초 뒤 특별 통행증+장부 지급, 청사 정문 앞으로 이동 → 정문 통과 후 집무실에 가면 **대면 장면**부터 시험 |
| `V3_TEST_LEADER = true` | 시작 7초 뒤 곧바로 **승계 장면(유언 승계)** → 통치 메뉴 시험 |
- 시험이 끝나면 다시 `false` 로 되돌리세요. (한 번에 하나만 켜는 것을 권합니다.)
