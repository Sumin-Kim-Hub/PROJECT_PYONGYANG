# PHASE 0 — 설계 문서

작성일 2026-11-12. 사실(확인됨)과 추정/계획을 구분해 적습니다.

## 1. 기술적 실현 가능성

| 항목 | 판단 | 근거 |
|---|---|---|
| 스마트폰만으로 3D 게임 제작 | 가능성 있음, 불편함 큼 | Godot에 Android 에디터가 있고 공식 문서가 2D/3D 프로젝트 제작·내보내기를 지원한다고 설명 |
| Android 에디터 요구사항 | 확인됨 | Android 5+, OpenGL 3 이상 |
| Android 에디터 제약 | 확인됨 | Gradle 빌드·Android 플러그인 불가, C# 불가, 외부 스크립트 에디터 불가, Vulkan Forward+ 비권장, 폰 화면에 최적화된 UI 아님, 삼성 키보드 입력 버그(Gboard 권장) |
| APK 내보내기 (폰에서) | **미확인** | 공식 문서에 가능하다는 문장은 있으나 필요한 템플릿·키스토어·SDK·JDK 설명이 없음. 데스크톱 문서는 내보내기 템플릿과 키스토어 필요, "Use Custom Build" 끄면 일반 APK, 라고 안내 |
| 코딩 없이 진행 | 가능 | Claude가 완성된 파일을 제공하고, 사용자는 열기·실행·오류 복사만 수행 |
| "실제 평양 전체 + 상세 내부 + 수십 NPC" | **비현실적** | 폰 성능·무료 에셋·1인 제작 한계. 아래 축소 범위 적용 |

**결론:** 작은 구역 + 단순 입체 형태(블록아웃) + 모듈식 내부 공간으로 단계적으로 키우는 계획은 현실적입니다. 가장 큰 불확실성은 "폰에서 APK 내보내기" 하나이며, 가능한 한 빨리 시험해야 합니다.

## 2. 현실적 게임 규모 (모바일 기준 초기 목표)
- 동시에 보이는 건물 수십 채, NPC 동시 활동 약 10~15명 (PHASE 4 시작 시 5명부터)
- 지도 한 구역 약 500m x 500m, 이후 구역을 추가
- 건물 내부는 **별도 씬**으로 분리하고 들어갈 때만 로드 (실내외 로딩 분리)
- 외관은 낮은 폴리곤 + 단순 텍스처, 그래픽 품질은 성능 확인 후 단계적으로 상향
- 목표 30FPS, 이후 60FPS 검토

## 3. 세계관 취급 원칙
- 배경은 "현대 북한을 모티브로 한 **가상의 세계**"입니다.
- 공개적으로 알려진 외관·생활 요소를 참고할 수는 있지만, 비공개 시설의 내부 구조는 전부 **게임용 창작**입니다.
- 게임 안에서도 비밀시설은 "가상 설정"임을 분명히 표시하고, 실제 확인된 사실처럼 서술하지 않습니다.
- 지도부 시설도 실제 내부 구조를 주장하지 않는 가상 공간으로만 구현합니다.

## 4. 무료 에셋 / 환경 제작 방법 (계획)
아래는 일반적으로 알려진 무료 소스이며, **사용 전에 각 에셋의 라이선스를 확인**해야 합니다. 지금 프로토타입은 외부 에셋을 하나도 쓰지 않습니다.
1. 코드 생성 블록아웃 (현재 방식): 라이선스 문제 없음, 용량 최소
2. CC0 에셋 팩: Kenney, Quaternius (건물/소품/캐릭터), Poly Haven·ambientCG (텍스처, 하늘)
3. Godot 안에서 CSG/박스 조합으로 건물 내부 모듈(복도, 계단, 방) 제작
4. 소리: 라이선스가 명확한 CC0 소스 우선
5. 한글 글꼴: Noto Sans KR 등 OFL 글꼴 (사용 시 라이선스 확인)
- 유료 에셋·유료 API는 도입하지 않으며, 비용이 생길 수 있는 선택지는 먼저 설명하고 동의를 받습니다.

## 6. 첫 프로토타입 정의 (PHASE 1)
성공 기준 (실행하면서 확인할 것):
1. 앱이 열리고 3D 도시가 보인다
2. 왼쪽 조이스틱으로 이동, 오른쪽 드래그로 카메라 회전, JUMP/RUN 동작
3. 건물·기념탑·기둥에 부딪혀 통과하지 못한다
4. 카메라가 벽을 뚫고 들어가지 않는다
5. 좌상단 FPS가 30 이상 유지된다
6. (별도 시험) APK로 내보내 설치·실행된다

## 7. 개발 로드맵
| 단계 | 핵심 | 완료 판정 |
|---|---|---|
| 1 | 이동·카메라·터치·간단한 도시 | 폰에서 실행됨 |
| 2 | 평양풍 구역 확장 + 지도 | 지도에 발견 장소 기록 |
| 3 | 건물 내부 + 문/엘리베이터 | 실내외 이동 |
| 4 | NPC 생활 | 시간표대로 움직임 |
| 5 | 가상 비밀시설 | 지하 구역 탐험 |
| 6 | 첩보 | 발각·문서·임무 |
| 7 | 완성도 | 사운드·저장·최적화 |
| 8 | APK 배포 | 설치 후 플레이 |

## 8. 단계별 테스트 계획
- 매 단계: 실행 → 이동/충돌/카메라 회귀 확인 → FPS 확인 → 문서 갱신
- 성능 점검 지표: 좌상단 FPS, 발열 체감, 10분 연속 플레이 시 프레임 저하 여부

## 9. 위험요소와 대응
| 위험 | 대응 |
|---|---|
| 폰에서 APK 내보내기 불가/불안정 | 가장 먼저 시험. 막히면 대안(PC 잠시 사용, 무료 CI) 제시 — 계정·한도 문제가 있으니 동의 후에만 |
| 처음 실행 시 코드 오류 | 오류 글씨를 받아 최소 수정 |
| 폰 성능 부족 | 설정값(그림자, 거리)으로 조정, 건물 병합/LOD |
| 작은 화면에서 Godot 에디터 조작이 불편 | 코드·씬은 Claude가 파일로 제공, 사용자는 열기/실행만. 블루투스 키보드·마우스 권장 |
| 사용량 한도로 작업 중단 | 상태 문서 5종 + RESUME_PROMPT.md 유지 |
| 민감한 설정의 사실/창작 혼동 | 가상 설정 명시 원칙(3장) |
