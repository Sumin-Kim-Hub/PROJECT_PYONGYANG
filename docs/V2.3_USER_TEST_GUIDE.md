# V2.3 직접 테스트 안내 (폰만으로)

> 이 게임의 V2.2/V2.3 는 한 번도 실행된 적이 없습니다. 아래는 **내가 대신 못 한 테스트를 사용자가 폰에서 하는 순서**입니다. 각 칸에 `작동 / 안 됨 / 이상함` 만 적어서 보내 주셔도 충분합니다. 빨간 오류 글씨가 나오면 그대로 복사해서 보내 주세요.

## 0. 준비
1. `PROJECT_PYONGYANG_V2.3.zip` 을 풀어서 기존 `PROJECT_PYONGYANG` 폴더 위에 덮어씁니다. **보호 5개 파일(world_builder, camera_rig, player, touch_controls, game_config)은 직접 손본 것이 있으면 그 파일을 유지**하세요. (V2.3 의 보호 파일은 V2.1 사본과 같습니다.)
2. Godot 에디터에서 프로젝트를 열고 **디버거 > 오류** 탭을 열어 둡니다.
3. 실행합니다. 에디터 아래쪽 오류 탭에 빨간 글씨가 있으면 **그 글씨부터 보내 주세요.** (아래 테스트보다 이게 먼저입니다.)

## 1. 자체 점검 (게임이 대신 확인해 줌, 약 10초)
1. 새 게임을 시작하고 **10초쯤 기다립니다.**
2. 화면 위쪽에 검은 칸으로 `자체 점검 V2.3: 통과 N / 주의 N / 실패 N` 이 나옵니다 (40초 동안 보임).
3. **그 화면을 스크린샷**으로 보내 주세요. `[실패]` 줄과 `[주의]` 줄이 중요합니다.
   - `[실패] 이동 지점 ... 아래에 바닥이 없습니다` → 실내에서 나올 때 떨어지는 문제의 직접 단서입니다.
   - `[참고] 바깥 도착 좌표에 바닥이 없습니다` → 원래 좌표가 허공이었다는 뜻(안전 좌표 보정이 대신 처리함).
4. 아무것도 안 뜨면: 그것 자체가 중요한 정보입니다("점검 칸이 안 뜸"이라고 알려 주세요). `feature_flags.gd` 의 `V23_SELFTEST` 가 `true` 인지 확인.
5. 로그를 볼 수 있다면 `[PYONGYANG]` 으로 시작하는 줄을 복사해 주세요. 파일 `user://v22_selftest.txt` 에도 같은 내용이 저장되지만 폰에서는 열기 어렵습니다.

## 6. 성능과 소리
- 새 지역 근처, 지하, 광장에서 **화면 위 FPS 숫자**를 적어 주세요(처음 보는 실제 값입니다).
- 배경 가락이 나는지, 끊기는지, 사이렌이 나는지.
- 폰이 너무 느리면 `CROWD_COUNT` 를 줄이거나 `V22_AUDIO=false`.
