## V2.0 적용 방법 / 새 기능
1. 아래 "V1.0 적용 방법"과 똑같이 ZIP 을 풀어 덮어쓰기 하세요 (보호 5개 파일은 ZIP 의 `scripts/` 에 들어 있음 — 이미 손본 버전이 있으면 그 5개만 덮어쓰지 마세요).
2. 실행하면 먼저 **시작 화면**이 뜹니다. 저장이 있으면 `이어하기` / `새 게임`(저장이 지워지므로 한 번 더 눌러야 시작), 없으면 `게임 시작`.
3. 새 장소: 평양역 풍 역사(남서쪽 큰길 끝쪽, 지도의 '평양역' 표시, 택시 목적지에도 있음) → 안내원 김혜정과 이야기하면 평양역 임무가 시작. 역 앞 주차장에는 탈 수 있는 차 6대(경찰차 포함). 창전거리 풍(동쪽)·미래과학자거리 풍(서쪽)은 구경용 거리.
4. 시민과 대화할 때 `마음 나누기` → 작은 선물(사탕/차) / 도와드릴까요 / 조심하라고 알린다. 시민마다 한 번씩 신뢰가 오릅니다. 사탕·차는 평양역 대합실의 매점에서 얻을 수 있습니다.
5. 설정(메뉴 > 설정)에 `날씨 변화`, `FPS 표시`, `시야 거리`가 추가되었고 바로 적용됩니다. 화면 왼쪽 위의 작은 글씨가 `FPS · 날씨 · 메모리` 입니다 (FPS 는 폰이 실제로 보여 주는 값).
6. 메뉴를 열어 둔 동안은 시간·시민·날씨가 멈춥니다.
7. 새 스위치: `ENABLE_V2`, `V2_LANDMARKS`, `V2_STATION`, `V2_WEATHER`, `V2_QUESTS`, `V2_TITLE`.
8. V2 테스트 체크리스트는 `TODO.md` 의 "V2.0 테스트 체크리스트", 항목별 실행 검증 상태는 `V2_VERIFICATION_REPORT.md` 에 있습니다. APK 는 만들지 못했습니다(아래 "APK 만들기" 참고).

## A. 업데이트 적용 (이미 프로젝트를 쓰고 있을 때)
1. `PROJECT_PYONGYANG_update_v0.1.0.zip` 을 스마트폰에 저장하고, **`PROJECT_PYONGYANG` 폴더가 들어 있는 바로 윗 폴더(예: Documents)에 압축 해제**합니다. ZIP 안에 `PROJECT_PYONGYANG/` 폴더가 이미 있어서 "병합/덮어쓰기"를 선택하면 기존 프로젝트에 합쳐집니다.
   - 새로 생기는 폴더: `scripts/core`, `scripts/data`, `scripts/interaction`, `scripts/interior`, `scripts/npc`, `scripts/city`, `scripts/ui`
   - `scripts/main.gd` 와 문서(.md)는 덮어써집니다.
   - **`world_builder.gd`, `camera_rig.gd` 는 ZIP 에 들어 있지 않으므로 직접 수정하신 내용이 그대로 유지됩니다.**
2. 만약 `main.gd` 를 직접 수정하셨다면 덮어쓰지 말고, 아래 두 부분만 `main.gd` 에 직접 추가하세요.
   - 맨 위 `const` 들 옆에: `const Flags = preload("res://scripts/data/feature_flags.gd")`
   - `_ready()` 맨 끝에 (`player.setup(controls, rig)` 아래):
```gdscript
	if Flags.ENABLE_INTERACTION:
		var sys_script = load("res://scripts/interaction/interaction_system.gd")
		if sys_script != null and sys_script.can_instantiate():
			var sys = sys_script.new()
			sys.name = "InteractionSystem"
			add_child(sys)
			sys.setup(player, rig, controls, world)
		else:
			push_error("InteractionSystem 스크립트를 불러오지 못했습니다. 기본 게임은 계속 실행됩니다.")
```
3. Godot 에서 프로젝트를 열고(처음엔 새 파일을 가져오느라 시간이 걸림) **▶ 실행**.

1. Godot **4.3 이상** Android 에디터 설치 (공식 사이트 또는 Google Play). Android 5+ / OpenGL 3 기기.
2. 전체 프로젝트 ZIP 을 Documents/Downloads 에 풀고 Godot 에서 `project.godot` 를 Import → ▶.

| 상호작용 | 가까이 가면 **노란 둥근 버튼**과 안내 문구가 나타남 → 버튼 누르기 (대화, 입장, 앉기, 문, 조사, 줍기) |
| 대화 | 선택지를 누르기. 선택지가 없으면 대화창 탭. 오른쪽 위 X 로 닫기 |
| 일어서기 | 앉아 있을 때 같은 버튼(일어서기) |
| 지도/가방/임무/메뉴 | 화면 오른쪽 위 둥근 버튼 |
| 카메라 거리 | 오른쪽 위 **+ / −** (또는 메뉴) |
| 저장/불러오기/새 게임 | 메뉴. 앱을 나가면 자동 저장되고, 다시 켜면 자동으로 이어짐 |

(PC 테스트: WASD 이동, Shift 달리기, Space 점프, 방향키 카메라, E 상호작용)

## C. Android 테스트 체크리스트 (이 순서대로 확인하고 결과를 알려 주세요)
**1단계 – 기본 (이전에 되던 것이 그대로 되는지)**
- [ ] 실행되고 도시/플레이어가 보인다 · 이동/카메라 회전/점프/달리기가 된다
- [ ] 화면 왼쪽 위에 `mv(...) ... mode:FREE 08:30` 같은 초록 글씨가 보인다 → 허브가 실행 중이라는 뜻
- [ ] 오른쪽 위에 지도/가방/임무/메뉴 버튼, 위쪽 가운데에 시계와 임무 한 줄이 보인다
- [ ] 한글이 네모(□)로 깨져 보이지 않는다 (깨지면 알려 주세요)

**2단계 – 임무 1: 찻집**
- [ ] 광장 근처에서 "새 장소 발견" 알림 · 찻집 간판이 보인다 (지도 > 발견한 장소)
- [ ] 찻집 입구에서 '입장' 버튼 → 암전 → 찻집 내부
- [ ] 한미정에게 말 걸기(대화 선택지) → 소파/의자에 앉기 → "임무 완료", 소개장 획득, 다음 임무 시작
- [ ] 일어서기 버튼으로 일어서고 나가기 버튼으로 밖에 나온다

**3단계 – 시민/시간**
- [ ] 시민들이 돌아다닌다 · 말을 걸면 멈추고 바라본다 · 사람마다 대사가 다르다
- [ ] 시간이 흐르고(메뉴/시계) 해 질 무렵 하늘 색이 바뀐다 · 밤에는 시민이 줄어든다

**4단계 – 임무 2: 행정사무소**
- [ ] 소개장을 가지고 직원 박정숙과 대화 → 허가증 → 안쪽 문(문서실) 열기 → 낡은 장부 줍기 → 임무 완료

**5단계 – 임무 3: 정보원 접촉 (길다)**
- [ ] 대학생 최민호 대화(임무 시작) → 호텔 안내원 윤서현에게 선택지 "푸른 우산입니다" → 열쇠
- [ ] 아파트 3동 입구 입장(열쇠 필요) → 거실 책장 '살펴보기' → 책장이 사라지고 비밀 통로 → 내려가기
- [ ] 지하: 통제실 문 열고 보안 카드 → 서버실 문(카드로 열림) → 기밀 문서 줍기
- [ ] 경비 시야에 오래 있으면 경계 게이지가 차고 발각되어 아파트로 돌아온다 (문을 닫으면 시야가 막힘)
- [ ] 계단이나 비상 출구로 올라와 최민호에게 문서 전달 → 임무 완료

**6단계 – 기타**
- [ ] 호텔 엘리베이터 위/아래 이동, 201호 문 열기
- [ ] 벤치에 앉기, 큰길 차량이 지나가고 앞에 서면 멈춘다
- [ ] 메뉴 > 저장 → 앱 종료 후 재실행 → 위치/가방/임무가 이어진다
- [ ] 메뉴 > 새 게임(2번 누름) → 처음 상태로 다시 시작되고, 앱을 껐다 켜도 옛 저장이 되살아나지 않는다
- [ ] 밤(22시 이후)에도 화면이 완전히 새까맣지 않고 푸른빛으로 보인다
- [ ] FPS (좌상단 또는 이전 표시) 30 이상

## 느릴 때 / 문제가 있을 때
- `scripts/data/feature_flags.gd` 에서 값을 바꾸세요: `CROWD_COUNT = 4`, `EXTRA_BUILDINGS = 4`, `ENABLE_VEHICLES = false`, 특정 기능을 `false` 로 끄면 나머지는 그대로 실행됩니다. (예: `ENABLE_INTERACTION = false` 면 v0.0.1 상태로 돌아갑니다)
- 그림자 끄기: `scripts/game_config.gd` 의 `SHADOWS = false`, `TARGET_FPS = 30`
- 한글 글꼴: `res://assets/fonts/NanumGothic.ttf`(나눔고딕, SIL OFL — `assets/fonts/OFL.txt`)가 포함되어 있고, 자동 로드 `KoreanFontEnforcer`(`scripts/core/korean_font_enforcer.gd`)가 `assets/theme/default_korean_theme.tres` 를 읽어 게임 전체(HUD·버튼·Label3D) 기본 글꼴로 지정합니다. 웹 버전은 시스템 글꼴을 쓸 수 없어 이 파일이 없으면 한글이 □ 로 나옵니다.
- 디버그 글씨(좌상단)를 끄려면 `SHOW_DEBUG_STATE = false`.
